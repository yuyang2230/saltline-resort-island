# 盐线：度假岛·船厂

单文件浏览器 FPS。整个游戏就是目录里的一个 `index.html`（约 1.4 MB）：Three.js、全部几何体、材质贴图、音效、语音都打包在这一个文件里，不需要下载任何资源，不需要构建，也不依赖网络。

场景是一座晴日正午的热带度假岛船厂：白色混凝土地坪、干船坞、红色龙门吊、两艘锈橙色货轮靠泊码头、深色天窗厂房、红白条纹烟囱塔，西南与东南是白沙滩、棕榈树和礁石岬角，海面上是远山剪影。

## 玩法

你扮演一名受雇的渗透员，潜入度假岛的船厂区：

1. **切断 3 个上行中继站**（分别位于船坞堆场、厂棚、码头）。在中继站前按住 `E` 切断。
2. 切断过程中会被安保系统发现，需要对抗两类敌人：**无人机**（空中，会咬住你不放）和**机器犬**（地面，贴身缠斗）。
3. 三个中继全部切断后，安保网络下线，赶到码头梯口**乘快艇撤离**，任务完成。

游戏全程有中文无线电播报，用浏览器自带的 speechSynthesis 发音。

## 本地运行

方式一：直接双击 `index.html`（推荐用 Chrome / Edge）。

方式二：起一个本地静态服务器，然后访问 `http://localhost:8000`：

```bash
python -m http.server 8000
```

打开页面后**点击画面开始游戏**，浏览器会请求捕获鼠标（Pointer Lock），点击即锁定并进入战斗。

## 操作

| 按键 | 功能 |
|---|---|
| `W` `A` `S` `D` | 移动 |
| 鼠标 | 视角 |
| 鼠标左键 | 开火 |
| 鼠标右键 | 瞄准 |
| `E`（按住） | 切断中继站 |
| `Shift` | 疾跑 |
| `Space` | 跳跃 |
| `C` 或 `Ctrl` | 蹲下 |
| `R` | 换弹 |
| `F` / `V` | 近战 |
| `P` / `Esc` | 暂停 |

- 如果浏览器无法锁定鼠标（如某些内嵌环境），会退化为**按住拖动转视角**：移动鼠标转向、靠住屏幕边缘持续转向，左键仍可开火；方向键或 `I` `J` `K` `L` 也能转身。
- 支持手柄：双摇杆移动与视角、RT 开火、LT 瞄准、A 跳跃、B 蹲下、X 换弹、Y 切断中继、L3 疾跑、Start 暂停。
- 靠近中继站时屏幕下方会提示"按住 E"；按住别松，进度条走完才算切断。

## 调试参数（URL 查询串）

| 参数 | 作用 |
|---|---|
| `?shot=1` | 截图模式：跳过标题屏与鼠标锁定提示，画质锁定为 `test`，阴影逐帧更新 |
| `?cam=x,y,z,lx,ly,lz` | 指定相机位置 `(x,y,z)` 与注视点 `(lx,ly,lz)`，常与 `?shot=1` 连用取景 |
| `?q=low\|medium\|high\|ultra\|test` | 画质档位（低/中/高/极高/测试）；不指定时自动为本机选档 |
| `?fov=` / `?exposure=` | 覆盖视场角 / 曝光 |
| `?seed=` | 换随机种子（默认 4207） |
| `?wet=1` | 回切雨天（本作默认晴日，雨天系统代码保留） |
| `?noaudio=1` / `?autostart=1` | 静音 / 跳过标题直接开始；`#bench` 基准测试模式会自动带上这两个 |

另有两个控制台接口：`window.__G`（引擎全局）与 `window.__setShot({cam:...})`（运行时改相机）。

## 技术要点

- **单文件、全程序化生成**：地形、建筑、货轮、龙门吊、棕榈、天空、云、海面全部由代码生成；材质贴图通过 MRT 离屏烘焙实时产出（混凝土锈蚀、船体漆面、湿沙等），整个仓库没有任何外部图片/音频/模型文件，运行时不发任何资源请求。
- **Three.js（r163）** 打包内嵌，渲染器自身关闭内建色调映射，色调映射放进自定义后期链里做。
- **AgX 色调映射**：后期链内按 AgX 官方变换用 GLSL 自实现（含 `agxDefaultContrastApprox`），高动态范围的高光与蓝天更耐压。
- **软阴影**：自研 PCSS patch（`SALTLINE_SHADOW`），Vogel 盘采样 + 搜索半径估计，低配自动降采样数。
- **多 pass 后期链**（`SALTLINE_POST`）：泛光、自适应曝光、动态分辨率缩放等；初始化失败会打印日志并回退到前向渲染，不白屏。
- **音效全部由 WebAudio 合成**：枪声、脚步（按混凝土/水/沙分面）、无人机旋翼、机器犬伺服等数十种音色均为程序化波形，无任何音频文件。
- **speechSynthesis 中文播报**：无线电台词走浏览器语音合成（`lang="zh-CN"`），系统无可用中文语音时只静默降级、不报错。
- 自动画质：按帧时间动态降分辨率/降档（`?dynres=0` 可关）。
